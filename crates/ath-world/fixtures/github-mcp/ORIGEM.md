# Origem

Definições de ferramentas (nome, descrição, `inputSchema`, `outputSchema`, `annotations`) copiadas
sem alteração dos instantâneos `pkg/github/__toolsnaps__/*.snap` do servidor MCP oficial do
GitHub, https://github.com/github/github-mcp-server (licença MIT), commit
`67d4dc489700ec955ad255d098396dd86c729523` (16/11/2026).

A face `ath-world mcp` as anuncia como o servidor real as anuncia, para que o cliente MCP do ARX
seja conferido sem rede contra os mesmos esquemas. O comportamento das ferramentas é um modelo
simplificado, sobre as tabelas `gh_issues` e `gh_comments`.
